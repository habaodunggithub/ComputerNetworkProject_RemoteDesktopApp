Khả năng toàn diện

Khám phá tất cả các tính năng mạnh mẽ của NetControl Pro

Giám sát (Surveillance)

Các công cụ theo dõi và giám sát máy mục tiêu theo thời gian thực

Desktop View

Xem màn hình máy mục tiêu theo thời gian thực với độ trễ cực thấp.

  • H.264 video streaming
  • Điều khiển chuột & bàn phím
  • Hỗ trợ tiếng Việt (Unicode)
  • Chụp ảnh màn hình
  • Block input người dùng

Webcam

Stream và ghi hình webcam từ máy mục tiêu.

  • Live streaming MJPEG
  • Ghi hình MP4
  • Tự động phát hiện thiết bị
  • Tải video về máy

Keylogger

Ghi lại tất cả phím bấm trên máy mục tiêu.

  • Real-time streaming
  • Window Title Logging
  • Phân biệt physical/injected
  • Hỗ trợ Unicode

Quản lý Hệ thống

Công cụ quản lý tiến trình, ứng dụng và file hệ thống

Applications

Quản lý các ứng dụng đang chạy trên máy mục tiêu.

  • Liệt kê ứng dụng đang chạy
  • Khởi chạy ứng dụng
  • Force quit ứng dụng

Processes

Task Manager từ xa - quản lý tiến trình hệ thống.

  • Liệt kê tất cả tiến trình
  • Hiển thị PID, Memory, Path
  • Kill process theo PID
  • Chạy command/path

File Explorer

Duyệt và quản lý file system từ xa.

  • Duyệt tất cả ổ đĩa
  • Upload/Download file
  • Tạo file/folder
  • Xóa file/folder
  • Xem nội dung file
  • Hỗ trợ đường dẫn tiếng Việt

Red Team Operations

Công cụ trích xuất dữ liệu và thông tin nhạy cảm

Password Stealer

Trích xuất mật khẩu đã lưu từ trình duyệt.

  • Chrome, Edge, Brave, CocCoc
  • Opera, Vivaldi
  • DPAPI Decryption
  • Export CSV

Cookie Stealer

Lấy cookies qua Chrome DevTools Protocol.

  • Bypass App-Bound Encryption
  • CDP Remote Debugging
  • Session Hijacking
  • Chrome v127+ support

Browser History

Trích xuất lịch sử duyệt web.

  • Chromium-based browsers
  • Firefox support
  • SQLite parsing
  • Export CSV

WiFi Searcher

Lấy thông tin WiFi đã lưu trên máy.

  • Liệt kê tất cả profiles
  • Hiển thị SSID + Password
  • Đánh dấu mạng đang kết nối
  • Copy all to clipboard

Tính năng khác

Các chức năng bổ sung và điều khiển hệ thống

Chat System

Giao tiếp 2 chiều với máy mục tiêu.

  • Cửa sổ chat popup
  • Force foreground
  • Real-time messaging

Power Control

Điều khiển nguồn máy mục tiêu.

  • Shutdown từ xa
  • Restart từ xa

Auto Discovery

Tự động tìm kiếm Agent trong mạng LAN.

  • UDP Beacon
  • Leader Election
  • Multi-Gateway support
